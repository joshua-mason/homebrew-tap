# joshua-mason/homebrew-tap

Homebrew formulae for my tools.

```sh
brew install joshua-mason/tap/mac-headroom
```

## mac-headroom

Find where macOS disk space went and clear caches safely. It measures and
explains rather than guessing: every cleaner states why removing it is safe,
nothing is deleted without `--yes`, and every command can answer in JSON so an
agent can drive it.

Source and documentation: https://github.com/joshua-mason/mac-headroom
